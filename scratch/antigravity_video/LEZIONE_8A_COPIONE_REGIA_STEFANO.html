FASE 2: Configurare la Chiave API Una Volta per Sempre (Global Variables)
Minuti 04:30 - 09:00
Cosa mostrare a schermo
1. In alto a destra clicca su Profilo → Settings → Global Variables.
2. Clicca Add New e compila: Type = Credential (spiega che resta criptata e nascosta), Name = GEMINI_API_KEY, Value = incolla la chiave gratuita Gemini creata al Modulo 06.
3. Mostra l'opzione Apply To Fields (oppure mostra dove apparirà sui nodi tramite l'icona del Globo 🌐).
Cosa dire a voce (Copione Stefano)
"Prima di mettere il primo nodo sulla tela, facciamo una cosa da professionisti: salviamo la nostra chiave gratuita di Gemini (quella creata nel Modulo 06) una volta sola, per sempre. Così non dovrete mai più copiarla e incollarla in ogni progetto.

Andate su Profilo → Settings → Global Variables → Add New. Scegliete Type Credential — mi raccomando Credential, così Langflow la cripta e la nasconde a schermo — chiamatela GEMINI_API_KEY e incollate la chiave. Con Apply To Fields o cliccando sull'icona del Globo 🌐 direttamente dentro i nodi, la richiamerete con un click in totale sicurezza."
FASE 3: Primo Flusso Visuale Zero-JSON (Chat Input → Prompt → Model → Chat Output)
Minuti 09:00 - 14:30
Cosa mostrare a schermo
1. Crea un flusso vuoto (o apri il template base Basic Prompting) e trascina/collega in sequenza i 4 blocchi: Chat Input → Prompt → Model (Google Generative AI / Gemini) → Chat Output.
2. Nel nodo Model (Google Generative AI / Gemini), clicca sull'icona del Globo 🌐 nel campo API Key e seleziona GEMINI_API_KEY.
3. Apri il campo Template del nodo Prompt, scrivi un'istruzione semplice e clicca sul tasto Playground laterale per testare la risposta dal vivo, poi modifica il Prompt e rilancia subito il test.
Cosa dire a voce (Copione Stefano)
"Adesso costruiamo il nostro primo flusso visuale a prova di errore! Guardate i 4 mattoncini collegati da sinistra a destra: Chat Input dove entra la domanda dell'utente, Prompt dove diamo le istruzioni, Model impostato su Google Generative AI (Gemini), e Chat Output dove esce la risposta.

Nel nodo del modello non incollo nessuna chiave: clicco sull'icona del Globo 🌐 e scelgo GEMINI_API_KEY. Fatto! Ora apriamo il Playground qui a lato: scrivo una richiesta, premo Invio ed ecco la risposta di Gemini in diretta. E se cambio una frase dentro il nodo Prompt? Riprovo nel Playground e cambia subito comportamento: zero JSON scritto a mano, solo logica visuale!"
