Lezione 4A • Antigravity Skills

Obiettivo della Lezione

Trasformare una procedura aziendale ripetitiva (report settimanale, analisi preventivi, check email) in una Skill permanente (.gemini/skills/nome/SKILL.md) riutilizzabile con un solo comando.

Prima di iniziare a registrare

  • Cartella di progetto aperta in Google Antigravity IDE
  • 2 file di appunti grezzi di esempio (es. note_lunedi.txt, note_venerdi.txt)
  • Mostrare differenza tra scrivere un prompt lungo ogni volta vs richiamare una Skill
