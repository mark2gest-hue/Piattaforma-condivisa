Lezione 8A • Langflow Desktop

Cosa imparerai in questo modulo

Dopo aver studiato API e JSON (Moduli 05–08) e prima di passare alle automazioni su n8n (Modulo 09), imparerai a installare Langflow Desktop senza Docker, salvare la chiave API Gemini in modo sicuro e creare il tuo primo flusso AI collegando nodi e frecce senza scrivere una riga di JSON.
Checklist Operativa Passo-Passo
AI Pro • Pratica
1. Download & Installazione Desktop (Zero Docker)
• Vai su https://www.langflow.org e clicca su Download Desktop.
• Scarica .dmg se usi Mac oppure .exe se usi Windows e installa come una normale app.
• Apri Langflow Desktop: al primo avvio attendi 30–60 secondi mentre prepara l'ambiente Python locale.
2. Chiave API Unica e Criptata (Global Variables)
• Recupera la chiave gratuita Gemini creata nel Modulo 06.
• In alto a destra vai su: Profilo → Settings → Global Variables → Add New.
• Imposta Type: Credential (così rimane criptata e nascosta), Name: GEMINI_API_KEY e incolla la tua chiave.
• Usa Apply To Fields oppure selezionala sui nodi cliccando l'icona del Globo 🌐 nel campo API Key.
3. Costruisci il Primo Flusso Visuale & Testa nel Playground
• Crea un nuovo flusso (o parti dal template base) e collega in ordine:
Chat Input → Prompt → Model (Google Generative AI / Gemini) → Chat Output.
• Nel nodo Model clicca sul Globo 🌐 e seleziona GEMINI_API_KEY.
• Apri il pannello laterale Playground, invia un messaggio e prova a modificare il testo del nodo Prompt per vedere cambiare subito la risposta.

Esercizio Pratico — Assistente Risposte Clienti

Nel nodo Prompt scrivi le regole del tono di voce della tua azienda (es. cortese, chiaro, max 5 righe, con saluto finale firmato) e collega una variabile {richiesta}. Apri il Playground e testa 3 richieste reali di clienti (preventivo, reclamo, richiesta info) rifinendo il prompt fino a ottenere risposte pronte da inviare.
Riepilogo Errori Comuni da Evitare
Troubleshooting
  • Primo avvio lento: se Langflow impiega 30–60 secondi ad aprirsi la prima volta non chiudere l'app: sta inizializzando l'ambiente Python locale.
  • Chiave incollata in chiaro: usa sempre Settings → Global Variables con Type Credential e richiamala col Globo 🌐, mai in chiaro dentro i nodi.
  • Frecce non collegate o tipo errato: verifica che ogni porta di uscita (es. Message del Prompt) entri nella porta compatibile del nodo successivo prima di aprire il Playground.
