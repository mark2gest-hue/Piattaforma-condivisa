Lezione 8B • Agente RAG & API

Obiettivo della Lezione

Passare da una chat lineare al nodo Agent con documenti PDF e Tool collegati in Langflow Desktop, mostrando come ogni flusso espone subito un endpoint tramite la tab API per essere orchestrato da n8n a partire dal Modulo 09.

Prima di iniziare a registrare

  • Langflow Desktop aperto con la variabile globale GEMINI_API_KEY già configurata nella Lezione 8A
  • Un file PDF aziendale leggero e leggibile pronto sulla Scrivania (es. listino prezzi, brochure servizi o regolamento interno da 2–5 pagine)
  • Pre-verificare che il template RAG / flusso con nodo Agent + File (o Vector Store) + Tool giri pulito prima del ciak
FASE 1: Da Flusso Lineare a Vero Agente con Documenti e Memoria
Minuti 00:00 - 04:00
Cosa mostrare a schermo
1. Webcam frontale di Stefano, poi mostra a schermo il confronto tra il flusso lineare della 8A (Chat Input → Prompt → Model → Chat Output) e un flusso con nodo centrale Agent dotato di porta Tools e conoscenza documenti.
Cosa dire a voce (Copione Stefano)
"Bentornati nella lezione 8B di AIutiamoci! Nella 8A abbiamo costruito un flusso lineare: entra una domanda, passa nel Prompt, Gemini risponde. Molto utile, ma ha un limite: conosce solo ciò che gli scrivete nel Prompt, non conosce i vostri documenti aziendali e non sa usare strumenti esterni.

Oggi sostituiamo la catena rigida con il nodo Agent. Un Agente ragiona prima di rispondere, decide da solo se gli serve leggere un vostro PDF o usare un Tool collegato, e ci prepara esattamente la strada per i Moduli su n8n e sui sistemi RAG (Retrieval-Augmented Generation)!"
FASE 2: Caricare un PDF Aziendale & Collegare un Tool all'Agente
Minuti 04:00 - 10:00
Cosa mostrare a schermo
1. Apri un template RAG oppure aggiungi il nodo File / Vector Store caricando il PDF aziendale di esempio.
2. Collega l'uscita dati/tool verso la porta Tools del nodo Agent (impostando il modello Gemini con il Globo 🌐 GEMINI_API_KEY) e aggiungi anche un secondo Tool pratico (es. Calculator o URL / Web Search).
3. Apri il Playground e fai una domanda specifica i cui numeri o dettagli esistono solo dentro il PDF caricato, mostrando nei log/pensiero dell'Agente la consultazione del documento.
Cosa dire a voce (Copione Stefano)
"Prendiamo un PDF reale della nostra azienda — ad esempio un listino prezzi o una brochure — e carichiamolo nel blocco File / Vector Store (usando il template RAG integrato in Langflow). Poi colleghiamo sia la base conoscenza del PDF sia un Tool pratico direttamente alla porta Tools del nostro nodo Agent.

Apriamo il Playground e chiediamo: 'Qual è il prezzo e la condizione prevista per il servizio X?'. Guardate cosa succede: l'Agente non inventa nulla, consulta il nostro documento, verifica i dati e ci risponde con precisione millimetrica basandosi sui nostri file!"
FASE 3: Il Ponte verso n8n (Tab API in Alto a Destra & Export JSON)
Minuti 10:00 - 15:00
Cosa mostrare a schermo
1. Clicca in alto a destra sul pulsante/tab API (API Access) per mostrare l'URL endpoint HTTP e lo snippet pronto (cURL/Python/JS).
2. Mostra poi il menu del flusso per fare Export → Download .json (e accenna a Import per condividere flussi nel team).
Cosa dire a voce (Copione Stefano)
"E ora la magia che collega tutto il percorso! Guardate in alto a destra questo pulsante: API. Ogni singolo flusso che disegnate su Langflow diventa istantaneamente un indirizzo chiamabile dall'esterno! E se volete salvarlo o passarlo a un collega, dal menu potete fare Export in un file .json e re-importarlo con un click.

Tenete sempre a mente questa regola d'oro:
Langflow fa il cervello AI visuale, mentre n8n (dalla Lezione 09) fa il postino automatico h24 tra Email, Fogli Google e Telegram.
Da n8n vi basterà fare una chiamata a questa API di Langflow per avere un'azienda che legge le email in ingresso, consulta il vostro listino PDF e prepara la bozza di risposta da sola!"
