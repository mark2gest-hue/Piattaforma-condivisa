Lezione 8B • Agente RAG & API

Cosa imparerai in questo modulo

Trasformerai un semplice flusso chat in un vero Agente Visuale capace di leggere documenti PDF aziendali, utilizzare Tool collegati e trasformarsi in un endpoint chiamabile via API da n8n (Modulo 09).
Checklist Operativa Passo-Passo
AI Pro • Pratica
1. Perché passare al nodo Agent
• Una chat lineare risponde solo con ciò che sa già il modello.
• Il nodo Agent invece ragiona, decide quali strumenti attivare e consulta i tuoi documenti prima di rispondere (base dei sistemi RAG).
2. Caricare un PDF Aziendale & Collegare un Tool
• Assicurati di avere già configurato Settings → Global Variables → GEMINI_API_KEY (Type: Credential) dalla Lezione 8A e richiamala sul nodo Agent tramite l'icona del Globo 🌐.
• Usa un template RAG (o collega il nodo File / Vector Store) e carica il tuo file PDF aziendale.
• Collega la conoscenza del documento e un Tool (es. Calcolatrice o Ricerca) alla porta Tools dell'Agent, poi interrogalo nel Playground.
3. Il Ponte verso n8n (Tab API & Export .json)
• Clicca sulla tab API in alto a destra: ogni flusso Langflow è subito un endpoint pronto per essere chiamato dall'esterno.
• Dal menu del flusso puoi fare Export / Import .json per salvare o condividere i tuoi agenti.
• Regola d'oro: "Langflow fa il cervello AI visuale, n8n (dalla Lezione 09) fa il postino automatico h24 tra Email, Fogli Google e Telegram."

Esercizio Pratico — Agente su Listino o Brochure PDF

Carica un listino prezzi o una brochure aziendale in PDF nel flusso con nodo Agent, apri il Playground e fai 3 domande reali che ti fanno di solito i clienti (prezzi, tempi/condizioni e un dettaglio specifico presente nel testo). Verifica che le risposte citino i dati esatti del documento prima di passare al Modulo 09 su n8n.
Riepilogo Errori Comuni da Evitare
Troubleshooting
  • PDF scansionato come immagine: se il PDF non contiene testo selezionabile, l'Agente non può leggerlo direttamente; usa un PDF testuale esportato da Word/Docs.
  • Chiave mancante sul nodo Agent/Embeddings: controlla che tutti i nodi AI del flusso abbiano la variabile GEMINI_API_KEY collegata via icona Globo 🌐.
  • Tool scollegato: verifica che il connettore del documento/tool entri nella porta Tools del nodo Agent, altrimenti l'Agente risponderà senza consultare il file.
